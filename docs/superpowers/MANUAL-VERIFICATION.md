# 交互重设计 · 手工核查清单

六个阶段 + 一次缺口收口 + 数字人解耦 + 本体日期类型的手工验证项合并成一份，共 **70 项**（其中 22 项标了⚠️）。自动化测试
（后端 2267 / 前端 619）覆盖不到的就是这些：真实浏览器、真实驱动、
真实的多页面串联。

**用法**：起前后端，按顺序走。带 ⚠️ 的是对应计划自己标注的「不能跳过」项
——它们是那个阶段面向用户的核心承诺，其余项失败可以记账后续修，这些不行。

```bash
# 后端（当前没在跑）
.venv/Scripts/python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
# 前端
cd frontend && npm run dev
```

## 已知的、清单不覆盖的
